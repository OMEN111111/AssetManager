# Blender 桥接插件 · 版本日志

> 版本规则：插件版本与 AssetManager 软件版本**解耦**。第一版 `0.1.0`，之后每次改动只递增第三位
> （`0.1.1`、`0.1.2`…）。所有 Blender 系列目录（`3.6/`、`4.0/`、`5.2/`…）共用同一个插件版本号。
> 只改插件时不改编软件版本号。

## 0.1.4 — 2026-10-21

**明确范围 + 一轮优化**：本插件只做「从 AssetManager 导入」（模型 / 材质 / 贴图），
**不做回库（pack）、也不做拖放**；收到 `pack` 之类任务直接回一条清楚的「不支持」错误。

优化：

- **贴图节点缓存**：同一张贴图在一个材质里只建一个 `TexImage`（打包图 ARM 同时喂 AO/粗糙/金属），
  通道抽取结果也缓存；实测材质节点 25 → 23、连线 33 → 31，同一张图不再重复建节点
- **赋材质不再清空槽位**：单槽物体直接替换该槽（面分配不变）；多材质物体把旧的**本插件材质槽**换掉，
  没有本插件材质时追加一个新槽（原来会把多材质模型清成单材质）；结果里分别报「原地更新 / 替换旧槽位 / 追加到新槽位」
- **撤销**：导入模型、赋材质后各 push 一个撤销点，Ctrl+Z 能撤回
- **导入提示更清楚**：同一素材重复导入时提示「集合 X 现有 N 个，会累加」
- **空闲轮询降频**：连续 20 次取不到任务后从 0.8s 降到 2s 一次，来任务立刻恢复
- 面板顶部写明「接收：模型导入 / 材质重建 / 贴图」，连接状态下面显示待执行任务数
- 代码整理：删掉 `pack` 特殊分支（并入统一的不支持错误）、`_existing_ours`/`_is_ours`/`_undo` 收拢公共逻辑

集成测试新增「打包图只建一个贴图节点」断言；Blender 5.2 真机 **50 项断言全绿**。

## 0.1.3 — 2026-10-21

**材质原地重建**：同一个素材反复发送不再堆材质。

- 建材质前先找同名、且带 `assetmanager` 标记的旧材质：找到就在它身上原地重建（清空节点 → 重搭 BSDF + 材质输出 → 重新接贴图）
- 好处：材质不会变成 `X.001`/`X.002`；已经赋了这个材质的对象**自动跟着更新**（改贴图/强度后重发一次即可，
  不用重新给对象赋材质）
- 只动本插件建的材质；用户自己的同名材质没这个标记，不会被覆盖（会另建一个，实测 `AMTest_Foreign.001`）
- `_apply_material` 遇到对象已经在用这个材质时不清空槽位，消息里报「其中 N 个对象原地更新」
- 集成测试新增第 6 步（7 项断言：同数据块 / 不堆重名 / 重建后基础色仍连着 / 有材质输出节点 /
  对象槽位不增长 / 提示文案 / 不劫持用户材质）

## 0.1.2 — 2026-10-21

**端口跟随**：修复「软件显示未检测到 Blender」——软件重启、便携版每次解压到新路径都会换端口，
而插件原来只在心跳失败时才重新找端口，于是留在旧端口上装死。

- 每 5 秒核对 `%LOCALAPPDATA%\AssetManager\bridge.json`（软件写的端口定位文件）：
  端口变了就切过去并**立刻心跳**，本地事件里留一条「端口跟随到 N（软件换端口了）」
- 定位文件指向的端口探不通（软件已退出/残留）→ 保持原端口，由心跳失败分支回退扫描 8787–8805，
  实测 8787 → 8791 自动切、8791 关掉后自动回到 8787
- 三个系列同步到 0.1.2；`tools/test_blender.py` 新增第 5 步「端口跟随」，用假服务 + 假定位文件断言
  切换/不抖动/恢复（实测 41 项断言全绿）

## 0.1.1 — 2026-10-21

**Blender 5.2 支持**（新增 `5.2/` 系列，在 Blender 5.2.0 LTS 上后台 + GUI 双模式端到端实测通过）。

- 5.x 兼容层：
  - `ShaderNodeHueSaturation` / `ShaderNodeMixRGB` 的 `Fac` 输入改名为 `Factor` → 统一用 `_ins(node, "Fac", "Factor")` 取
  - BSDF 节点名会随界面语言本地化（中文界面是「原理化 BSDF」）→ 一律按 `node.type == "BSDF_PRINCIPLED"` 找
  - `Material.use_nodes` 在 5.x 标记弃用（6.0 移除）→ 只在还没节点树时才写，避免向控制台刷弃用警告
  - 注册类失败不再静默 `pass`，改为打印堆栈（5.x 起 `bpy.types` 不再暴露 Python 类，出问题只能靠日志）
- 集成测试 `tools/test_blender.py`：装插件 → 材质 8 通道逐插槽断言 → FBX/GLB/OBJ/STL 导入（集合/选中/光标/材质）→ 贴图载入 → 真实队列三条任务（材质/导入/贴图）全部 `done`；实测覆盖 37 项断言。
- 3.6 / 4.0 系列同步到同一实现主体（只差头部元数据），版本号一并对齐到 0.1.1。

## 0.1.0 — 2026-10-21

首版（插件版本从这一版起独立编号，不再跟随软件版本）。

- **目录按 Blender 版本分槽**：`3.6/`（Blender 3.3–3.6 LTS）、`4.0/`（Blender 4.0+），
  文件名固定 `assetmanager_blender.py`；新增 `tools/sync-blender-bridge.mjs` 保证各系列实现主体不分叉。
- **版本独立可查**：`bl_info["version"] = (0,1,0)`、`BL_VERSION = "0.1.0"`；心跳上报
  `{plugin, series, blender}`，软件面板与 `targets.blender.version` 直接显示插件版本与系列。
- **端口自动发现**：先读 `%LOCALAPPDATA%\AssetManager\bridge.json`（软件写真实端口，可能漂移），
  再扫 8787–8805；心跳失败时自动重新探测并切换端口。
- **模型导入**：FBX / GLB / glTF / OBJ / DAE / STL / PLY / USD / Alembic，导入后放进以素材命名的集合、
  移到 3D 光标、自动选中；导入的网格直接套素材材质。
- **材质重建**：基础色、粗糙度、金属度、法线（GL/DX 自动翻转）、AO 相乘、自发光、不透明度、
  高度凹凸（法线 + 凹凸串联）、UV 平铺/旋转/位移、HSL、`intensity` 强度、`invert` 反相，全部接上。
- **贴图任务**：贴图载入为图像数据块并在图像编辑器里显示第一张。
- **节点/操作符兼容层**：`ShaderNodeMix` ↔ `MixRGB`、`Emission Color` ↔ `Emission`、
  `surface_render_method` ↔ `blend_method`、`wm.obj_import` ↔ `import_scene.obj` 等差异集中处理，
  同一份实现跑 3.6 与 4.x。
- **面板**：显示插件版本 / Blender 版本 / 系列、连接状态、执行中任务、最近 6 条事件；
  端口改动即时生效，timer 只注册一次，断开时清空未执行任务。
- **未实现**：拖放、打包回库（`pack`）——任务类型收到 `pack` 会明确报错而不是静默失败。
